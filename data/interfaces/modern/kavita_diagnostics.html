Summary of Library Analysis:
  • Total Series Analyzed: -
  • Unique Publisher Roots: -
  • Already Active Mappings: - (Skipped; no remote action)
  • Ineligible Backoff Mappings: - (Skipped; in retry backoff window)
  • Ambiguous Mappings: - (Skipped; requires manual Kavita cleanup)
  • Unmapped Roots to Sync: - (Will be created or associated)
  • Skipped (Flat Layouts): - (No publisher subfolder)
  • Skipped (Missing Folders): - (Path not found on disk)
Important Notices & Requirements:
1. Exact Literal Paths: Mylar will send each series' literal publisher directory path (e.g. /comics/Image Comics) directly to Kavita.
2. Storage & Access: Kavita must have access to identical folder paths within its own environment. Container mount mappings and permissions remain the user's responsibility.
3. Remote Operations: This action may create new libraries and queue initial library-specific scans on your Kavita server for unmapped roots.
4. Active Mapping Protection: Existing active publisher libraries will not be modified or rescanned by this backfill.
